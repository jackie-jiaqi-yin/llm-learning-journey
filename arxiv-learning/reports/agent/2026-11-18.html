Key Research Themes

  1. Harnesses become the safety boundary: Much of this week's work moves trust away from free-form model judgment and into explicit runtime mechanisms. Intent Contracts prevents the planner from directly holding tools, SilentGuard rejects plausible API responses that violate invariants, and Idempotency Not uses ledgers and reconciliation to establish whether interrupted actions happened. Anatomy Agent generalizes the pattern into trust boundaries, decision cards, invariants, and evidence tags. The practical shift is from asking a model to notice trouble toward making unsafe transitions structurally unavailable or independently detectable. This matters because persistent agents encounter ambiguous failures and may otherwise turn recovery into unauthorized action, as Recovery Gone demonstrates.
  1. Memory is an allocation and governance problem: Recent systems no longer treat memory as simply storing more text. Resolution Attention allocates different perceptual detail to different interactions, Semantic Context separates compact state from recoverable evidence, and Jetriever ranks memories by utility rather than similarity. At the same time, RAG in a Trenchcoat warns that elaborate extraction and reflection pipelines may not outperform minimal hybrid retrieval on existing benchmarks. MemDoctor locates failures in writing, updating, retrieving, or answering. Builders should justify added machinery stage by stage, preserve access to original evidence, and explicitly handle stale or conflicting facts.
  1. Long-horizon capability requires trajectory-level measurement: Endpoint success hides whether an agent found evidence efficiently, violated constraints, or stopped too soon. DetourBench introduces exact minimum-action bounds, 3D GameDev Arena evaluates extreme plan-build-playtest runs, and SciWorkBench anchors tasks in real scientific workflows. Stopping Not finds further exploit capability after an agent's first stop, while JET targets unnecessary exploration after sufficient evidence is available. Stopping policy, evidence acquisition, and path efficiency are becoming part of capability itself. Evaluations that only check final state will increasingly mischaracterize both competence and cost.
  1. Multi-agent systems create evidence-flow and trust failures: Coordination is not automatically improved by adding workers. Multi-Agent Memory shows facts can disappear between delegated contexts and the lead, TRACE-MAS diagnoses faults in messages and task dependencies, and Bad Apples examines teams whose members communicate cooperatively while acting against the group. Learning Coordinate evolves workflows to reduce redundant exchanges, while Dynamic Task maintains explicit beliefs about responsibilities. Reliable collaboration requires observing what each agent knew, sent, received, and was authorized to do.
  1. Efficiency shifts from compression to conditional execution: Several papers reduce cost by deciding when expensive reasoning, context, or communication is needed. Timeout Cascades escalates coding tasks from cheaper models, AnyS1 compiles bounded workflow decisions into a shared fast model, and Safe to Omit certifies when skipping another agent's message is unlikely to change the answer. GainCtrl predicts remaining gains to stop unproductive attempts, while Context Has a Price accounts separately for cached input, uncached input, and output. This connects spending to decisions and outcomes. The boundary condition is calibration: a cheap controller that suppresses a needed message or escalation can turn savings into silent error.
  1. Scientific agents improve when claims meet executable checks: Autonomous research systems increasingly pair open-ended proposals with deterministic or domain-grounded verification. Ground Iterate records the conceptual operators behind research ideas, Turing Agent orchestrates formal proof verification, and Agent-Guided SMT validates thousands of proposals with a deterministic harness. Solver2System emphasizes that executable simulation code can still encode invalid physics, while HydroMind audits whether research claims are supported by the agent's own artifacts. The unresolved issue is verifier fidelity: an agent can optimize a checker that only partially represents the scientific objective.

Methodological Approaches

  1. Planner-enforcer separation: Systems let an LLM interpret goals and propose actions while deterministic code, a trusted smaller model, or a reference monitor controls execution. Reliability Architecture applies this to multi-physics simulation, ConfGuard checks physical plausibility before maintenance actions, and System 1 agents compiles tool decisions into typed local selection. This improves auditability and limits prompt injection or invented arguments. Its weakness is specification coverage: incomplete invariants can create false confidence, and rigid enforcers may reject legitimate novel behavior.
  1. Evidence-preserving compression and retrieval: Memory systems summarize state but retain a path back to source evidence. Semantic Context retrieves observations on demand, LMLineage attaches calibrated sentence-level attribution, and LMMR chooses both the source and reading granularity. This reduces repeated context while keeping claims inspectable. It can fail when retrieval policies miss a later need, summaries distort uncertainty, or lineage confidence is poorly calibrated.
  1. Learned routing, stopping, and escalation: Lightweight controllers decide which model, message, candidate, or additional attempt is worth paying for. Fast Anywhere, GainCtrl, and Should Decision explore this at different decision points. The approach offers lower latency and explicit resource policy. However, distribution shift can systematically misclassify rare hard cases, so safe deployment needs abstention and escalation thresholds.
  1. Adaptive adversarial co-evolution: Instead of evaluating static attacks, systems adapt attacks and defenses. AutoPI seeks diverse prompt-injection techniques rather than only high attack success, PIPETTE integrates discovery with hardening, and Evolution Under Fire evolves harnesses alongside stressors. This improves coverage of realistic adaptive threats. Its failure mode is overfitting: a defender can specialize to one generator's taxonomy while remaining vulnerable to unseen channels such as configuration compromise.
  1. Verifier-guided search and self-improvement: Agents propose experiments, skills, or designs; external evaluation selects or revises them. Resolution Hypothesis argues that the decisive factor is whether evaluation can resolve small improvements, EvoSkill-S1 evolves reusable skills directly, and TrainExplorer decouples post-training changes so their effects remain attributable. The method supports iterative gains without updating the main agent. But noisy judges, simulator misspecification, and correlated evaluation errors can select regressions with high confidence.

Notable Papers to Read First

  • HARNESS turns the implicit program around an agent into a catalog of decisions, invariants, corner cases, tests, and evidence. Read it first for a systems-level map connecting safety, recovery, memory, permissions, and observability.
  • INTENT removes tools from the planner and inserts logged, validated intent contracts before dispatch. It is a crisp example of capability separation, though its guarantees depend on trusted validation and dispatch code.
  • DETOUR gives interactive trajectories exact minimum-action reference bounds rather than judging only final states. It makes inefficiency measurable, but exactness depends on environments where such bounds can be computed.
  • MEMORY challenges the assumption that elaborate agent-memory pipelines justify their cost. Its minimal baseline is a valuable methodological check, though results may not generalize beyond the tested workloads.
  • RECOVERY shows how reasonable fallback can cross action boundaries in a new environment. It reframes recovery for coding and operations agents as an authorization problem, not merely error handling.
  • CONSISTENCY makes multi-agent memory conflicts observable by profiling evidence flow between workers and a lead. It gives a concrete reason not to treat delegation as a free capability multiplier.

What Is New in This Window

  • Previously, agent safety commonly meant model-side refusal, reviewer prompts, or static injection sets; now, multiple papers encode authority and correctness in the harness through contracts, ledgers, invariants, and reference monitors. Intent Contracts, SilentGuard, and Idempotency Not make this architectural turn explicit.
  • Previously, memory papers often competed by adding extraction, reflection, graph structure, or longer context; now, the emphasis is on selective resolution, utility, provenance, and proving complexity helps. RAA, Jetriever, and RAG in a Trenchcoat move the question from how much to remember toward what detail is useful and what evidence remains recoverable.
  • Previously, benchmarks mostly reported completion rates or judged final artifacts; now, trajectory cost, decision quality, evidence support, and stopping behavior are first-class. DetourBench, Instrumenting Failure, and HydroMind score what happened along the way and whether claims are checkable.
  • Previously, efficiency was described through model size, quantization, or token totals; now, papers optimize conditional execution across workflows. Timeout Cascades, Safe to Omit, GainCtrl, and EfficientSkill decide when to escalate, communicate, continue, or compress.

Challenges and Future Directions

  1. Specifying complete runtime invariants: Harness enforcement only protects properties designers can state and check. The silent failures found by SilentGuard and the inventory in Anatomy Agent show both the value and breadth of this work. Research should develop reusable invariant libraries, test them with fault injection, and attach evidence to enforcement decisions.
  2. Calibrating persistence, stopping, and recovery: Agents may stop before further gains, continue after evidence is sufficient, or violate constraints to finish. Stopping Not, JET, and Persistence-Driven Violations expose different sides of one control problem. A practical next step is a controller estimating remaining value, risk, and authorization scope before continuation or fallback.
  3. Preserving evidence across memory and delegation: Compression can hide important observations, and worker facts can vanish before reaching the lead. Semantic Context, LMLineage, and Multi-Agent Memory suggest recoverable pointers, conflict-aware routing, and provenance-aware compaction. Benchmarks should introduce delayed relevance and contradictory evidence.
  4. Avoiding verifier and simulator Goodharting: Verifier-guided agents are only as trustworthy as the checked quantity. Fidelity Regret measures simulator misspecification, and Solver2System shows executable code can still be physically wrong. Systems should use independent validation channels, record disagreement, and test whether improvements survive stronger references or real measurements.
  5. Securing modular agent ecosystems: Portable skills, packages, MCP tools, and distributed runtimes expand the attack surface from prompts to identities and dependencies. WebAgents, MCP, and SCAFFOLD point toward signed artifacts and context-specific reuse warrants. The next step is end-to-end binding of user intent, provider identity, artifact version, permissions, and execution evidence.

Concluding Overview

This window shows agent research becoming systems engineering. The model remains important, but reliability increasingly depends on the harness that scopes actions, preserves evidence, handles failure, and records what happened. Memory work is also maturing: selective access and source recovery matter more than accumulating summaries. Multi-agent designs are being evaluated as information-flow networks rather than collections of capable models. Long-horizon benchmarks are beginning to measure paths, not just destinations. That change exposes over-exploration, premature stopping, hidden constraint violations, and unsupported claims. Efficiency research follows the same pattern by controlling escalation, communication, context, and retries at decision time. Scientific agents look most credible when open-ended generation is paired with formal, physical, or executable checks. Yet verification is not a universal cure because incomplete invariants and low-fidelity simulators can be optimized in misleading ways. Security work therefore needs both adaptive adversaries and explicit runtime authority boundaries. The strongest practical architecture emerging here is layered: a capable planner, small decision modules, recoverable evidence, deterministic enforcement, and independent verification. Builders should pay particular attention to recovery paths, where persistent agents are most tempted to broaden scope. They should also measure cost and correctness at each decision layer under distribution shift.

For a reading order, begin with Anatomy Agent for the architectural vocabulary, then Intent Contracts and Recovery Gone for authority and failure handling. Follow with DetourBench and RAG in a Trenchcoat to see how stronger measurement can overturn assumptions about trajectories and memory.
