# Online Courses

Notes and insights from various online courses on AI and Large Language Models.

This section gathers practical course notes on generative AI, embeddings, vector stores, prompt engineering, AI agents, tool use, Hugging Face agent frameworks, and fine-tuning large language models.

## Available Courses

### [GenAI 5-Day Course with Google](https://github.com/jackie-jiaqi-yin/llm-learning-journey/tree/main/genai-5day-course-with-google)
Comprehensive 5-day course covering generative AI fundamentals and applications, including foundational models, prompt engineering, embeddings, vector search, vector databases, image and multimodal embeddings, graph embeddings, LlamaIndex, function calling, and generative agents.

[View course notes →](https://github.com/jackie-jiaqi-yin/llm-learning-journey/tree/main/genai-5day-course-with-google)

### [Hugging Face AI Agent Course](https://github.com/jackie-jiaqi-yin/llm-learning-journey/tree/main/huggingface-agent-ai-course)
Deep dive into building AI agents using Hugging Face tools and frameworks, including LLM messages, special tokens, tool specifications, thought-action-observation loops, ReAct-style reasoning, smolagents, code agents, and agentic framework patterns.

[View course notes →](https://github.com/jackie-jiaqi-yin/llm-learning-journey/tree/main/huggingface-agent-ai-course)

### [Hugging Face Fine-Tune LLM Notes](https://github.com/jackie-jiaqi-yin/llm-learning-journey/tree/main/huggingface-finetune-llm)
Fine-tuning notes covering chat templates, supervised fine-tuning with SFTTrainer, Low-Rank Adaptation (LoRA), evaluation, and building reasoning models.

[View fine-tuning notes →](https://github.com/jackie-jiaqi-yin/llm-learning-journey/tree/main/huggingface-finetune-llm)
